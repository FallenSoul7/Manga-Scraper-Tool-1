Phase 1 — PWA + Install + Smart Caching

1.1 — manifest.json

· File: public/manifest.json
· Content: app name (ComiHub), short name, icons (192×192 and 512×512 PNGs), "display": "standalone", background color #121212, theme color #ff6b6b.
· Place two placeholder icons in public/ (we'll replace later).

1.2 — Service Worker (public/sw.js)

· Caches:
  · Static assets (JS, CSS, fonts) → cache on first visit, serve from cache when offline.
  · API responses (/api/popular, /api/latest, /api/search, /api/tags, /api/details, /api/chapters, /api/pages) → cache for 1 hour.
  · Images (/api/image, direct image URLs) → cache for 30 days.
· Strategy: Cache First, then network update in background (stale-while-revalidate for API, cache-first for images).
· On fetch, check cache → return cached response if exists, else fetch from network and store in cache.

1.3 — Register the Service Worker

· In index.html, add <script> that registers /sw.js after window load.
· Also add <link rel="manifest" href="/manifest.json"> and <meta name="theme-color" content="#ff6b6b">.

1.4 — Install Button (Android & iOS)

· Android: capture beforeinstallprompt event, store it, show a dedicated "Install ComiHub" button inside the System page (or a small banner at the top). On tap, call prompt() and hide button after install.
· iOS: detect Safari / iOS, show a "Install" button that opens a full‑screen guide (animated or static images) showing:
  1. Tap Share icon
  2. Tap "Add to Home Screen"
  3. Tap "Add"
· After the app is launched from home screen (window.navigator.standalone === true), hide all install prompts.

1.5 — Settings → Storage UI (EXACTLY WHAT YOU ASKED)

Add a new "Storage" section inside the Settings page (or a dedicated tab in System page) that shows:

· Cache size: total MB used by the Service Worker cache (calculated by reading all cached entries' sizes). Displayed as Cache: 12.4 MB.
· Downloads size: if any chapters are downloaded (stored as blobs in IndexedDB or a separate cache), display total size as Downloads: 0 MB (or the actual size).
· Clear cache button: when tapped, clears all Service Worker caches (API, images, static) and shows a brief "Cache cleared" toast. Also resets cache size display.

How we calculate sizes:

· Use caches.open() to get each cache, iterate over all entries, sum up response.clone().blob().size (or use Content-Length header) in a background function.
· Store the result in localStorage and update on every cache change (or on demand when the Storage section is opened).
