While testing the website on mobile, I found several issues and improvements that need to be fixed.

First, in the browse section, when you scroll, the top options like Browse, Library, Updates, and History move down with you. That part is not a big problem, but there is a large empty space at the top. This space shows the settings button, and below it are those navigation options. Together, they take up a huge amount of space on the screen, which is not good for mobile and reduces the visible content area.

Second, inside a manga page, some manga have a lot of chapters, like 300 or more. Right now, you have to scroll all the way to the bottom to start from chapter 1. There is no “Read Chapter 1” button at all. There is also no button or arrow in the chapter area to change how the chapters are ordered. What should exist is a button that, when clicked, changes the order so the list starts from chapter 1 at the top and increases as you scroll down. If you click it again, it should switch back so the latest chapter is at the top and the numbers decrease as you scroll.

Third, the search does not seem to work properly. It shows results even if only a single letter matches. It should instead show results based on full words or meaningful matches. For example, if I type “hello,” it should show manga that contain the word “hello” in the title, not just anything that has one matching letter. It should be more accurate and also properly optimized for mobile use.

Fourth, the site is not fully optimized for mobile overall. The layout, spacing, and general design should be improved to fit mobile screens better.

Fifth, there is a major issue with translations (sources). Since comics can have multiple translations, like from Asura or official sources, the app either mixes them together or only shows one, similar to how Tachiyomi handles it incorrectly in some cases. There should be a feature in the chapter area where you can select a specific translation. There should be a button that shows all available translations for the manga you opened. When you select one, it should show a check mark indicating your choice. It should also display how many chapters each translation has next to it. As I scroll through the manga (manhwa), new pages of the chapter load dynamically. However, when the next part loads below, it causes the current content to shift slightly upward. This creates a shaky or jumpy effect while scrolling.

Because of this, the reading position is not stable. The screen moves unexpectedly whenever new content loads, making it harder to read smoothly. This issue is especially noticeable when continuously scrolling, as the page keeps adjusting itself instead of staying fixed.

The problem is essentially caused by dynamic content loading that changes the page height without preserving the user’s scroll position. This results in a layout shift that disrupts the reading experience and makes the interface feel unstable.
